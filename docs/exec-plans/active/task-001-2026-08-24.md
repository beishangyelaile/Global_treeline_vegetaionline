## 3. JRC式MMU实现

使用两次 `connectedPixelCount`，禁止继续使用：

```text
connectedComponents
reduceConnectedComponents
连通对象内pixelArea求和
先删除小森林再填孔
```

实现骨架：

```python
MMU_AREA_M2 = 5000
MMU_MAX_SIZE = 500

def apply_jrc_mmu(forest_raw):
    proj = forest_raw.projection()
    valid_mask = forest_raw.mask()

    pixel_area = ee.Image.pixelArea().reproject(crs=proj)

    count1 = forest_raw.connectedPixelCount(
        maxSize=MMU_MAX_SIZE,
        eightConnected=True,
    ).reproject(crs=proj)

    area1 = count1.multiply(pixel_area)
    small_component = area1.lte(MMU_AREA_M2)

    # 对森林像元加1不会改变其二值森林身份；
    # 对小非森林连通域加1，实现小间隙填充。
    forest_after_fill = forest_raw.add(small_component).gte(1)
    forest_after_fill_masked = forest_after_fill.selfMask()

    count2 = forest_after_fill_masked.connectedPixelCount(
        maxSize=MMU_MAX_SIZE,
        eightConnected=True,
    ).reproject(crs=proj)

    area2 = count2.multiply(pixel_area)
    forest_keep = area2.gte(MMU_AREA_M2)

    forest_clean_masked = forest_keep.updateMask(forest_keep)

    # 恢复成0/1图，但只能在GLAD原始有效范围内恢复0。
    forest_clean_binary = (
        forest_clean_masked
        .unmask(0)
        .updateMask(valid_mask)
        .toByte()
    )

    return forest_clean_binary
```

固定规则：

```text
maxSize = 500
eightConnected = True
第一次：area <= 5000 m²
第二次：area >= 5000 m²
面积：connectedPixelCount × pixelArea
顺序：先填小非森林间隙，再删除未达到MMU的森林斑块
```

禁止对全球影像直接无条件 `.unmask(0)`，否则可能将GLAD覆盖范围外的区域转换成非森林背景。

## 3. Step 2固定流程

对3 m和5 m产品分别执行：

```text

→ 1像元中值滤波
→ Laplacian 8邻域卷积

→ 300 m局地森林/非森林高程检验
→ 输出最终上树线
```

中值滤波和Zero Crossing必须在 `analysis_domain` 介入之前执行：

```python
smoothed_global = forest.focalMedian(
    radius=1,
    kernelType="square",
    units="pixels",
)

edge_global = (
    smoothed_global
    .convolve(ee.Kernel.laplacian8())
    .zeroCrossing()
    .gt(0)
)

mountain_edge = edge_global.And(analysis_domain).selfMask()
```

这样可以避免把GMBA或Sayre边界误识别为森林边缘。
