```python
FINE_CRS = "EPSG:4326"
FINE_TRANSFORM = [0.00025, 0, -180, 0, -0.00025, 90]

CLIMATE_CRS = "EPSG:4326"
CLIMATE_TRANSFORM = [1 / 120, 0, -180, 0, -1 / 120, 90]

AGGREGATION_MAX_PIXELS = 2048

source = ee.Image(source_treeline30m_asset).select([
    "treeline_2000_h3m_m",
    "treeline_2020_h3m_m",
    "treeline_2000_h5m_m",
    "treeline_2020_h5m_m",
])

means = (
    source.reduceResolution(
        reducer=ee.Reducer.mean(),
        bestEffort=False,
        maxPixels=AGGREGATION_MAX_PIXELS,
    )
    .reproject(ee.Projection(CLIMATE_CRS, CLIMATE_TRANSFORM))
)
```

不得使用 `bestEffort=True`。0.00025°到30角秒每个输出格通常涉及约34×34个输入像元，`maxPixels=2048`已经留有余量，不再使用4096。

输出波段和顺序必须保持：

```text

treeline_2020_h3m_mean_m
shift_2000_2020_h3m_m_per_year
treeline_2000_h5m_mean_m
treeline_2020_h5m_mean_m
shift_2000_2020_h5m_m_per_year
```

变化率仍为：

```python
shift = (mean_2020 - mean_2000) / 20
```

掩膜规则保持不变：只有2000和2020均有有效均值的格网才有有效变化率。
