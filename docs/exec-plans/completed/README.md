# Completed execution plans

本目录保存已经完成、取消或被取代的执行计划。活动计划只保存在相邻的 `active/` 目录中，并使用：

```text
task-<三位编号>-<YYYY-MM-DD>.md
```

当前首个计划示例为 `task-001-2026-08-24.md`。同一时间只允许存在一个活动计划；新任务使用递增编号，不复用历史编号。

任务结束后，将活动计划移入本目录并改为便于检索的归档名称，例如：

```text
2026-08-24-jrc-mmu.md
```

归档文件不能继续作为活动计划反复改写。若后来发现记录错误，应追加带日期的勘误，保留原始执行证据和状态变化。
